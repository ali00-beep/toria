# Проект: голосовой ассистент для ПК (Windows)

## Цель
Приложение на Python: горячая клавиша → запись голоса → текст →
нейросеть-диспетчер → короткий ответ вслух. Задачи для ПК диспетчер
передаёт нейросети-исполнителю. Код вслух не озвучивается.

## Правила работы
- Делай только тот этап, что указан в задаче. Лишних функций не добавляй.
- Перед большим изменением напиши короткий план и дождись ответа.
- Не перечитывай весь проект, трогай только нужные файлы.
- Пользователь не программист: объясняй просто, пиши, как запустить и проверить.
- В конце: 3–5 строк, что сделано и как проверить.

## Архитектура
- Настройки (горячая клавиша, модели) только в config.json.
- Ключи только в .env, никогда в коде и не в git (.env в .gitignore).
- Каждая нейросеть: провайдер (Ollama или API), адрес, модель, ключ.
  Используй формат запросов, совместимый с OpenAI, один код для всех.
- Модули: audio, stt, tts, llm, executor, ui.

## Безопасность
- Исполнитель работает только в папке workspace/.
- Удаление, установка и запуск программ только после подтверждения.
- Интернет только для запросов к настроенным API.
