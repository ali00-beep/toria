# Голосовой ассистент для ПК

Это первый этап проекта: удерживайте горячую клавишу, говорите, отпустите клавишу — запись сохранится в `workspace/test.wav`.

## Как запустить

1. Откройте PowerShell в папке проекта.
2. Один раз установите библиотеки:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запустите программу:

   ```powershell
   .\.venv\Scripts\python.exe src\record.py
   ```

4. Удерживайте `F9`, говорите в микрофон и отпустите `F9`.
5. Проверьте файл `workspace\test.wav`. Для выхода нажмите `Esc`.

Горячая клавиша и папка записи находятся в `config.json`. На этом этапе распознавание речи, API, озвучка и окно настроек не добавляются.

Используются `pynput`, `sounddevice` и `soundfile`: они подходят для Windows, дают глобальную горячую клавишу и позволяют записать звук напрямую в WAV без сложной настройки.
