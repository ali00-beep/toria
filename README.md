# Голосовой ассистент для ПК

Удерживайте горячую клавишу, говорите, отпустите клавишу — запись сохранится в `workspace/test.wav`, после чего программа распознает её на русском языке.

## Как запустить

1. Откройте PowerShell в папке проекта.
2. Один раз установите библиотеки:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запустите программу:

   ```powershell
   .\.venv\Scripts\python.exe src\record.py
   ```

4. Удерживайте `F9`, говорите в микрофон и отпустите `F9`.
5. Проверьте файл `workspace\test.wav`. Для выхода нажмите `Esc`.

Результат распознавания выводится в консоли как `Распознано: ...`. При первом распознавании модель Whisper может загрузиться из интернета и затем используется локально.

Горячая клавиша, папка записи и модель Whisper находятся в `config.json`. API, озвучка и окно настроек не добавляются.

Используются `pynput`, `sounddevice`, `soundfile` и `faster-whisper`: они подходят для Windows, дают глобальную горячую клавишу, запись в WAV и локальное распознавание с поддержкой GPU.
